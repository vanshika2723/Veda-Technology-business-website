# Veda Technology

A modern and responsive business website for **Veda Technology**, showcasing technology programs, IT & digital services, training, internship opportunities, and career-focused learning.

https://vanshika2723.github.io/Veda-Technology-business-website/

## 📌 About the Project

Veda Technology is a professional technology and digital services website designed to present the company's programs, services, training opportunities, internships, and contact information in a clean and modern interface.

The website focuses on providing visitors with an easy-to-use experience across desktop, tablet, and mobile devices.
